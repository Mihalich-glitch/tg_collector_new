# Telegram Corporate Collector
Простой и надежный инструмент для автоматического сбора сообщений из Telegram-чатов в базу данных PostgreSQL.

## Для чего это нужно? 
Бот позволяет сохранять историю переписки из групп и каналов (где он является администратором) в структурированном виде. Это полезно для создания архивов, аналитики данных или обучения нейросетей на реальных диалогах.

---

## Что должно быть на компьютере перед стартом
1. **Python 3.13+** (обязательно отметьте галочку "Add Python to PATH" при установке).
2. **PostgreSQL** (установлен и запущен как служба).
3. **VPN-клиент** (если вы находитесь в регионе, где доступ к Telegram ограничен).

## Быстрый старт

### 1. Подготовка папки
Откройте терминал (PowerShell) и выполните команды:

```powershell
# Клонируем проект (или просто скачайте архив и откройте папку)
cd "путь/к/вашей/папке"

# Создаем виртуальное окружение (изолированную песочницу для библиотек)
python -m venv win_venv

# Активируем его
.\win_venv\Scripts\activate

# Установим необходимые для работы библиотеки
pip install -r requirements.txt
```

### 2. Настройка конфигурации(.env)
Создайте файл '.env' в корневой папке проекта. Скопируйте туда это и вставьте свои данные:

```ini
# Токен вашего бота от @BotFather
BOT_TOKEN=123456789:AaBbCcDd...

# Ссылка на вашу базу данных PostgreSQL
# Формат: postgresql+psycopg://ЛОГИН:ПАРОЛЬ@localhost:5432/ИМЯ_БАЗЫ
DATABASE_URL=postgresql+psycopg://postgres:mypassword@localhost:5432/tg_collector
```

### 3. Настройка VPN и Прокси
Бот настроен на работу через локальный прокси-сервер.

*Как это работает:*
Большинство современных VPN-приложений (например, Nekoray, Amnezia, V2Ray) создают "локальный мост" на вашем компьютере. Бот подключается к этому мосту, чтобы обойти блокировку.

#### Где изменить настройки
Откройте файл 'app/main.py'. Найдите строку с настройкой прокси:
```python
proxy_url = "socks5://127.0.0.1:2080"
```
127.0.0.1 — это адрес вашего компьютера (localhost). Оставьте его как есть.
2080 — это порт, который использует ваш VPN.

## Подготовка базы данных
Перед запуском бота нужно создать саму "коробку" для данных:

1. Откройте pgAdmin 4.

2. Нажмите правой кнопкой на Databases -> Create -> Database....

3. Введите имя: tg_collector и нажмите Save.

---

## Запуск бота 
Убедитесь, что виртуальное окружение активно (win_venv), и пишите:
```powershell
python -m app.main
```
Если всё сделано правильно, в консоли появится:
```
🚀 Бот запущен и готов к работе!
```

## Как посмотреть собранные данные?
Пользователь с правами администратора может применить команду /export, чтобы получить csv-файл с сообщениями за определенный период.

```
/export "ДД.ММ.ГГ начала" "ДД.ММ.ГГ конца" 
```

Также можно использовать pgAdmin 4:

* Раскройте tg_collector -> Schemas -> public -> Tables.
* Нажмите правой кнопкой на messages -> View/Edit Data -> All Rows.
